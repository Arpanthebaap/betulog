# From repository to paper
1. Run a pilot with 2+ observers and one fully recorded plot; compute observer agreement and re-run power with real variances.
2. Add a small multi-plot dataset (at least 10 plots) from a partner.
3. Write the manuscript from the README structure. Candidate venues to check for scope, fees and article type: *Forest Pathology*, *Scandinavian Journal of Forest Research*, *Forest Ecology and Management*, *Methods in Ecology and Evolution* (software), *SoftwareX*.
4. Archive code and data with a DOI (Zenodo) before submission and follow the journal's AI-use policy.
