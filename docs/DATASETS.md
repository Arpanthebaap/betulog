# Data sources

1. **Own pilot data (recommended first).** Two or more observers score the same 20-30 birch trees independently (calibration), then one plot of 30-60 trees is fully recorded with symptoms, positions and isolates. This gives real variance estimates for the power tool.
2. **ICP Forests crown condition data.** The programme has monitored crown condition since 1985 using harmonised methods. Check the current data-request procedure and terms at https://www.icp-forests.net before relying on it; I have not verified access conditions.
3. **Project partners and national inventories.** Ask supervisors or partners about existing survey data; obtain written permission before use.
4. **Examples in `data/`** are synthetic and for format demonstration only.
