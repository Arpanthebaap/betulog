# Contributing

Thanks for helping. Betulog is a small single-file app, so changes are easy to review.

- **Bugs and ideas:** open an issue using the templates. For data problems include the CSV rows (remove anything sensitive such as exact private-land locations).
- **Domain feedback:** if you work in forest pathology, comments on the fields, scoring scheme and sampling prompts are the most valuable contribution.
- **Code:** keep `index.html` self-contained (no build step, no external scripts), keep it working offline, and keep accessibility (labels, keyboard focus, contrast). Test by opening the file and logging a tree, an isolate and exporting both CSVs.
- **Data:** never commit real survey data without the landowner's and your institution's permission.

By contributing you agree your contribution is released under the MIT licence.
